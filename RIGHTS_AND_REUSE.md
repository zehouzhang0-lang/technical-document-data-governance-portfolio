# Rights and reuse boundary

This repository contains only original portfolio prose, qualitative scale
descriptions, and synthetic examples. Public access does not grant any right to
reproduce the source technical documents or derived customer data.

The original corpus remains offline because it contains engineering drawings,
technical-standard text, real document identifiers and relationship data, and
materials carrying copyright, confidentiality, reproduction, or export-control
notices. Git LFS or private repository visibility would not resolve those
rights and confidentiality constraints.

No source PDF, screenshot, OCR excerpt, formal source JSON, real manifest,
customer identifier, manufacturer identifier, or original hash is included.
