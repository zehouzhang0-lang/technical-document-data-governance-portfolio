# Source provenance and sanitization

## Offline source boundary

- The original work and later portfolio audit were completed in 2026.
- Original project did not contain Git history.
- The source cache, tree outputs, final archive, review packet, prompts, and
  resume package remain offline.

## Read-only audit performed for this archive

- Counted tens of sequential root-tree directories.
- Parsed the hundred-plus delivered JSON files and the recursive-tree JSON files.
- Reconciled a manifest and a coverage table containing hundreds of mappings
  against files and raw-byte SHA-256 values.
- Verified that every recorded tree occurrence maps to a delivered file.
- Verified allowed field sets across the delivered documents and their
  reference records.
- Verified multiple same-name, raw-byte-different candidate groups.
- Re-parsed and recursively canonicalized delivered JSON, identifying multiple
  semantic duplicate groups that byte-level hashing had not detected.
- Reviewed historical quality-report statuses and found no complete global
  issue-to-fix-to-retest closure map.

## Sanitization

No original file, path, identifier, hash, drawing, screenshot, OCR excerpt,
technical-standard text, customer/manufacturer name, relationship record, or
exact source-derived project statistic was copied into the public repository.

The source corpus included copyright, confidentiality, reproduction, and
export-control notices. Repository visibility does not resolve those rights or
restrictions, so the public portfolio contains only qualitative method notes
and fully synthetic examples.
