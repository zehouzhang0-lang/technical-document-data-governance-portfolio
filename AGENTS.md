# Agent rules for this archive

This repository is a sanitized portfolio reconstruction. Treat all examples as
synthetic and keep them synthetic.

- Never copy the original PDFs, engineering drawings, screenshots, OCR text,
  JSON corpus, manifests, hashes, customer or manufacturer names, document
  identifiers, local paths, or run identifiers into this repository.
- Do not add production credentials, personal data, or real contact details.
- Do not describe this project as a deployed platform, a trained model, a
  knowledge graph, or a fully automated multi-agent system.
- Preserve the distinction between machine-verifiable delivery integrity and
  unmeasured semantic accuracy.
- Preserve the distinction between source-cache files, tree-level occurrences,
  byte-hash-selected delivery files, and normalized unique objects. They are
  different populations and must not be presented as one reduction funnel.
- Describe filename collisions as same-name, byte-different candidate versions.
  Do not claim that every candidate pair is semantically different.
- Files under `examples/synthetic/` are fictional demonstrations, not excerpts
  from the source corpus.
- `scripts/verify_demo.py` and `scripts/security_scan.py` were created during
  portfolio archiving; do not present them as the original delivery pipeline.
