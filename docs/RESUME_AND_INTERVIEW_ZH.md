# 简历与面试材料

## 推荐项目名称

**AI 辅助技术文档数据治理与质量验收**

## 数据分析 / 数据质量方向

- 在 AI 辅助下对 PDF、源 JSON 与 Excel 清单进行多源对齐，围绕数十个 root 构建递归引用树，将数百条树内正式记录按原始文件 SHA-256 归并为百余份交付 JSON。
- 设计并执行解析、允许字段、文件名、原始字节 hash、manifest 与 coverage 检查，实现全部文件可解析、全部记录可映射；归档复审进一步识别多组规范化语义重复并提出双层 hash 改进方案。
- 处理 OCR 噪声、低清扫描、缺失映射、同名文件冲突与信息性引用等异常，通过 evidence、变更记录和人工决策保留可追溯性。

## AIPM / AI 产品方向

- 将“核对 PDF 与 JSON 引用关系”的模糊需求拆成 root 识别、三源核验、递归展开、异常分流、质量验收与交付打包的标准工作流，并从单树 demo 扩展到数十棵引用树。
- 设计 Human-in-the-loop 机制：AI 辅助批量读取、候选抽取、比对和报告草拟，人工负责低置信内容、规则争议、风险接受与最终验收。
- 通过范围隔离的并行 AI 会话、写入边界、worker 报告和总控复核推进批量任务，并沉淀 manifest、coverage、QA report 和风险决策口径。

## 保守稳妥版

- 在 AI 工具辅助下核对 PDF、JSON 和 Excel 三类材料，整理数十棵技术文档引用树并形成百余份结构化 JSON 交付文件。
- 使用解析、字段、文件名、原始字节 hash 和 coverage 清单核对交付完整性，并对后续审计发现的语义重复保留透明说明。
- 对低清扫描、OCR 误识别、缺失文件和引用口径争议保留证据与人工决策记录，完成可追溯交付。

## 30 秒版本

这是一个 AI 辅助的技术文档数据治理项目。PDF、已有 JSON 和 Excel 清单之间存在遗漏、误识别与层级不一致，我负责把任务拆成多源核验、递归展开、异常分流和质量验收流程。最终整理数十棵引用树，将数百条树内记录归并为百余份交付 JSON，并完成解析、字段、manifest 和 coverage 检查。AI 负责批量辅助，我负责规则、争议判断和最终验收。

## 1 分钟版本

项目目标是把技术 PDF 中的多层引用关系整理为可追溯 JSON。难点不只是抽取，而是 PDF、已有 JSON 与 Excel 经常不一致，还存在低清扫描、缺失文件、循环引用和同名文件冲突。

我先用一棵 root 验证流程，再把任务标准化为三源对齐、子文件递归、终端叶子、异常记录和最终质检。AI 会话辅助批量读取和候选比对，我负责定义证据优先级、哪些情况需要人工确认，以及最终能否交付。原交付按文件原始字节 hash 归并为百余份 JSON，机器检查中全部文件可解析、数百条树内记录均可映射。后续归档审计仍发现多组规范化语义重复，所以我不会把“字节 hash 为零重复”夸大成“语义完全去重”，并把双层 hash 与正式 Schema 作为下一版改进。

## 常见追问

### 这算数据分析吗？

更准确地说，它属于数据质量治理和多源数据校验，不是传统 BI 或统计建模。它体现的是清洗、标准化、异常识别、质量指标和可追溯交付。

### 这算 AI 产品吗？

它不是上线平台，而是一套小型 AI 辅助工作流。我完成输入输出、流程拆解、人机分工、异常处理和验收标准设计，这些与 AIPM 工作方法相关，但不会称为完整产品。

### AI 做了这么多，你做了什么？

AI 提供批量读取、初步抽取、比对与报告草拟；我决定证据优先级、递归和终端叶子规则、去重口径、人工兜底与最终验收。AI 没有承担最终风险判断。

### 为什么不能说准确率 99%？

能证明的是格式与交付完整性：百余份文件可解析、允许字段一致、数百条记录可映射。没有官方逐条标准答案，因此不能计算严谨的语义准确率；低清扫描仍有残余风险。

### 为什么不同统计口径不能直接相减？

- 源缓存 JSON 是参考集合。
- 树内正式 JSON 是文件在不同树中的出现次数。
- 交付文件数按原始文件 SHA-256 归并。
- 规范化唯一对象数来自解析后的语义层去重。

它们不是同一总体，不能包装成单一的“清洗前—清洗后”漏斗，也不能把字节级唯一写成语义唯一。

### 最大的复盘是什么？

原项目只用原始文件字节 hash 判断重复，能发现完全相同文件，但不能识别仅格式、空白或键顺序不同的同一 JSON 对象。归档审计发现多组规范化语义重复。下一版会同时保存原始证据 hash 与规范化对象 hash，并为字段类型和枚举增加正式 JSON Schema。

## 不要写进简历

- 99% 准确率、100% 内容正确或全部 PDF 逐页人工核验。
- 百余份交付文件都是“完全去重”或“语义唯一”的数据对象。
- 所有同名候选都是真正的同名异内容；准确说法是同名、原始字节不同的候选版本。
- 完整 AI 平台、多智能体编排系统、知识图谱或训练 OCR/NLP 模型。
- 全自动完成、无人干预或管理真人团队。
- 把源缓存、树内出现次数与交付文件数写成一个直接压缩漏斗。
- 完整 JSON Schema 合规率 100%；原项目证据只支持允许字段检查。
- 全部树级问题已闭环；现有历史质量报告缺少完整关闭映射。
- 效率提升百分比、节省人天、真实客户采用、生产上线或业务收益。
